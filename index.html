Extensive reading

Menulis yang baik lahir dari membaca yang banyak. Saat membaca, catat pola yang kamu temukan.

Yang diperhatikan saat membaca ① Topic sentence — bagaimana paragraf dibuka. ② Transisi antar gagasan — however, in contrast, as a result. ③ Kolokasi — kata yang berpasangan alami (make a decision, pose a challenge, take a risk). ④ Ritme — perpaduan kalimat panjang dan pendek.
Catatan yang diawali tanda kutip mudah dipakai ulang saat menulis.

Kaidah agar progres nyata

  • Konsisten > banyak. 15 menit tiap hari mengalahkan 2 jam sekali seminggu.
  • Koreksi wajib dipahami. Jangan terima saran koreksi tanpa tahu alasannya.
  • Rewrite itu pengikat. Tulis ulang versi benar dari ingatan — di situlah pembelajaran terjadi.
  • Error log adalah peta. Minggu demi minggu, jenis kesalahan teratas akan bergeser — itu tanda berkembang.

Sinkron cepat via GitHub — tanpa setup rumit

Cara termudah menyimpan progress ke cloud & melihatnya di HP: hubungkan token GitHub-mu (2 langkah), dan semua perangkat yang memakai token yang sama akan sinkron otomatis. Data disimpan sebagai gist privat milikmu sendiri di GitHub — bukan pihak ketiga.

  1. Klik Buat token di GitHub ↗ — lalu klik Generate token di halaman itu (scope gist sudah otomatis).
  2. Salin token (ghp_…) → tempel di bawah → Hubungkan. Selesai.

Token tersimpan hanya di browser masing-masing perangkat (tempel lagi di HP nanti). Aman: gist bisa hanya dilihat/ambil/buat dengan GitHub milikmu, dan gist yang dibuat bersifat privat.

Yang ikut tersinkron: journal, cycle, error log, reading, streak, dan pengaturan. Draf editan journal/cycle tetap lokal per perangkat.

Firebase belum dikonfigurasi

Sinkronisasi cloud butuh project Google Firebase (gratis). Ikuti langkah ini:

  1. Buka console.firebase.google.com → buat project (nama bebas).
  2. Menu Build → Authentication → Get started, aktifkan penyedia Google.
  3. Tab Settings → Authorized domains → tambahkan domain tempat app ini di-hosting (mis. username.github.io). localhost sudah otomatis.
  4. Menu Build → Firestore Database → Create database (mode production). Tempel Security Rules dari README.md.
  5. Project settings → General → Your apps → Web app → daftarkan app → salin config ke file js/firebase-config.js.

Setelah file config diisi, muat ulang halaman ini.
